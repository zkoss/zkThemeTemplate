# Skill Gaps Log

Append-only record of ZK features that the harness missed and how we structurally caught them. See `doc/skill-feedback-loop.md` for the workflow.

## Columns

- **date**: ISO date the gap was identified
- **component(s)**: which component(s) the gap affects (comma-separated when shared)
- **gap**: one sentence — what was wrong
- **why-harness-missed-it**: one sentence — why the existing process didn't catch it
- **layer**: `skill` / `contract` / `agent` (or combination, e.g. `skill+agent`)
- **fix-location**: relative paths or section refs where the fix landed
- **retrospective**: one sentence after the fact — did the layered fix catch siblings, or did more gaps surface?
